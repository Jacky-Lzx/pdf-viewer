# 插件：命令与交互式视觉会话

Pagewing 不嵌入脚本引擎，也不增加 Cargo 依赖。插件是系统上的可执行程序，
通过 JSON 通信，Python/Shell 等解释器由插件自行选择。

- **API v2**：一个持续进程接收事件，维护交互状态，返回页面覆盖层和按键声明。
  适合 focus 阅读、阅读尺、文字区域着色等视觉交互。
- **API v1**：保留一次性工具命令，返回提示、剪贴板文本、跳页。

页面始终由阅读器渲染，插件描述效果，不逐帧生成或传输页面图片。
覆盖层只影响显示，不写入 PDF，也不改变导出图片、搜索或文字选择的数据。

## 安装与示例

目录在配置文件旁：`~/.config/pagewing/plugins/`；绝对路径的
`XDG_CONFIG_HOME` 设置会将其改为 `$XDG_CONFIG_HOME/pagewing/plugins/`。
**Plugins → Copy plugins folder** 可复制实际目录。

```text
plugins/
├── focus-reader/
│   ├── plugin.toml
│   └── plugin.py
└── copy-reference/
    ├── plugin.toml
    └── plugin.py
```

将仓库 `examples/plugins/focus-reader/` 整个目录复制到插件目录，检查代码后将清单的
`enabled` 改成 `true`。选择 **Plugins → Reload plugins**，打开 PDF 后运行
**Focus reader · j/k**。示例需要 Python 3，仅使用标准库。

默认保留三行明亮，其余页面变暗。`j/k` 或上下箭头移动一行；到达边界时进入下一页或上一页。
`Esc` 或 **Cancel plugin** 退出。扫描件没有文字行时改用可移动亮带，不需要 OCR。
清单的命令参数 `--lines 3` 可设为 1–20 行，`--opacity 0.72` 可设为 0–1。
文字顺序与 PDF 的文字层一致；复杂多栏、竖排或缺少准确文字层的文档不保证自然阅读顺序。

## 清单

```toml
api_version = 2
name = "Focus reader · j/k"
enabled = true
command = ["python3", "-u", "plugin.py", "--lines", "3"]
timeout_seconds = 5
```

`api_version` 必填，为 `1` 或 `2`；`name` 必填，1–128 字节。
`command` 为非空参数数组，参数原样传递，不进行 Shell、环境变量或 `~` 展开。
简单程序名从 Pagewing 进程的 `PATH` 查找；包含路径分隔符的相对程序路径按插件目录解析。
工作目录为插件目录。Finder 启动的 `PATH` 可能与终端不同，必要时指定解释器绝对路径。

`enabled` 默认 `false`，必须明确启用。`timeout_seconds` 默认 10，范围 1–120。
在 v2 中限制**每个事件**的响应时间，不限制会话的空闲时间或总时长。
清单上限 16 KiB，根目录最多 128 个条目，不递归扫描。错误清单独立显示，不影响其他插件。
停用可修改清单后 Reload，卸载可移走插件目录。插件不会自动运行。

## API v2：事件与状态

每个窗口最多运行一个插件。启动视觉插件后，其进程持续运行直到退出模式。
每个事件以一行 UTF-8 JSON 写入 stdin。插件必须为该事件返回**恰好一行** stdout JSON，
带相同的 `id`，并立即 flush。日志写 stderr；不支持主动发送未请求的回复。

```json
{
  "api_version": 2,
  "id": 1,
  "event": "activate",
  "context": {
    "document": "/absolute/path/book.pdf",
    "page": 3,
    "page_count": 24,
    "page_size": [600, 800],
    "rotation": 0,
    "zoom": 1.0,
    "viewport": [1000, 700],
    "scroll": [0, 0],
    "selected_text": "",
    "lines": [{"text": "A line of text", "rect": [60, 100, 450, 115]}],
    "lines_truncated": false
  }
}
```

事件包括：

| event | 触发条件 |
| --- | --- |
| `activate` | 当前页文字几何准备好后首次激活 |
| `page` | 当前页变化，新页文字几何已准备好 |
| `key` | 捕获的按键，顶层增加 `key`，例如 `"j"` |
| `selection` | 当前选中文字变化 |
| `view` | 缩放、旋转、滚动或窗口尺寸变化 |

每个事件都有完整的基本 context；只有 `activate/page` 携带 `lines`，插件应缓存它。
`page` 为从 1 开始的物理页码，不是 PDF 页码标签。`page_size` 和行矩形使用
**与阅读器文字层相同的页面坐标**：左上为原点，x 向右、y 向下，尚未应用用户阅读旋转或缩放；
已包含文档自身的裁剪和内置旋转。`rotation` 是用户附加的 0–3 个顺时针四分之一转。
`scroll/viewport` 使用界面逻辑像素，描述当前阅读视图，不是原始 PDF 底左坐标。
阅读器负责将覆盖层映射到屏幕，因此缩放、旋转、滚动及不同布局无需插件重新计算坐标。

行几何在后台文字提取完成后生成，每页最多 2048 行，每行预览最多 128 UTF-8 字节；
`lines_truncated` 表示超出行数上限。选中文字最多 4096 个 Unicode 字符。
无文字层时 `lines` 是空数组。整个事件上限 1 MiB。
不可表示为 UTF-8 的文件路径会报错，不会替换字符后传入错误路径。密码不会传给插件。

## API v2：绘制与交互

```json
{
  "id": 1,
  "capture_keys": ["j", "k"],
  "scene": {
    "dim": [0, 0, 0, 180],
    "pages": [{
      "page": 3,
      "holes": [[0, 100, 600, 155]],
      "rectangles": [{"rect": [60, 100, 450, 115], "color": [255, 220, 0, 50]}]
    }]
  },
  "reveal": [0, 100, 600, 155]
}
```

除 `id` 外所有回复字段可省略：

- `scene`：替换整个覆盖层场景。省略则保留；`{}` 清空。`dim` 是 RGBA（0–255），
  对所有显示的 PDF 页面进行统一遮罩；`holes` 是指定页上保持原亮度的矩形孔洞。
  孔洞可重叠，不会重复叠加暗度。`rectangles` 在遮罩上绘制带透明度的彩色矩形。
  覆盖层裁剪在页面内，不覆盖工具栏、侧栏、菜单，不改变鼠标命中测试。
- `capture_keys`：替换捕获列表，省略保留，`[]` 释放。
  支持无修饰的小写 `a`–`z`、`ArrowUp/Down/Left/Right`、`Space`，最多 32 个。
  仅正常阅读模式下优先于阅读器快捷键；输入框、菜单、帮助窗口、属性窗口及
  读者的链接提示/命名位置/组合键状态保留自己的输入。带修饰键的按键不捕获。
  `Esc` 始终由宿主保留为退出插件模式；在输入框/菜单内先执行其原有关闭行为。
- `reveal`：让当前页指定矩形进入阅读视口，可用来跟随移动的 focus 区域。
- `goto_page`、`copy_text`、`message`：与 v1 相同，跳页、复制文本或显示可复制的纯文本结果窗口。
- `deactivate: true`：插件主动结束会话，清除覆盖层并释放按键。

场景最多 64 个不重复的有效页，每页最多 64 个孔洞和 256 个矩形。
坐标必须有限且 x0 < x1、y0 < y1，绝对值不得超过 1,000,000，超出纸张的部分由宿主裁剪。
未知字段、非法坐标、越界页码或错误的 id 会结束会话，整个回复先验证后应用。

这是可扩展的二维覆盖层接口，目前不提供任意着色器、像素滤镜、图片替换、鼠标事件
或自定义原生控件。此类能力需要后续扩展协议，不能通过当前的矩形场景直接完成。

## 调度、退出与权限

视觉插件在独立后台线程与进程中运行，stdin/stdout/stderr 使用非阻塞管道。
同一时间只有一个事件等待响应，按键队列最多 16 个，视图变化合并并最多每 50 ms 发送一次。
未变化的视图不会反复发送事件；绘制使用保存在宿主内的场景，不需要逐帧 IPC。
只有插件活动时才创建会话线程/进程。stdout、stderr 各自上限 64 KiB，按事件重置；
管道写满也可以超时取消，不会阻塞阅读界面。

翻页立即移除旧场景、更新文档页次，并丢弃过期回复；新页几何就绪后继续同一个进程。
取消、关闭/替换/重新加载文档、异常退出、超时、非法协议或退出窗口时清除效果和按键，
结束插件进程组。宿主取消不承诺发送最后一条清理事件；插件不应脱离进程组或启动常驻服务。

**插件以当前用户身份运行，没有安全沙箱。** 只启用检查过且可信的插件。
它们拥有用户的文件与网络权限。协议及队列限制用于控制异常任务，不是 CPU、内存或磁盘硬配额。

## API v1：兼容的一次性工具

`examples/plugins/copy-reference/` 保留 v1 示例。stdin 接收完整对象后结束：

```json
{"api_version":1,"document":"/path/book.pdf","page":3,"page_count":24,"selected_text":"摘录"}
```

stdout 输出一个对象并以状态码 0 退出：

```json
{"message":"完成","copy_text":"摘录 — book.pdf, p. 3","goto_page":4}
```

字段均可省略；未知字段或越界页码使整个结果失败。非零退出显示错误和 stderr。
仍支持超时、取消和输出上限；不提供持续会话、按键捕获或视觉覆盖层。
